# スキルシートの紹介動画

進め方（中身を文字で決める → 完成に近い動画で方向を選ぶ → 仮アニメーションで直しの方向を選んで本番に入れる）と、選択票・仮アニメーション・拍の測り方は `motion-video` スキルにある。ここには、この題材だけの決めを置く。

再開するときは、まず `.tmp/videos/STATE.md`（現在地）と `.tmp/videos/opus-3/HANDOFF.md`（作り手への引き継ぎ書）を読む。

## 題材と事実

- 事実は README だけから取る。README に無い数字・社名・期間・成果は足さない
- 書かないもの: 約 1/3 削減・案件 1,000 件 × 1,000 名・5 分以内・3 サービス・マッチング 2 サイトの件数・CLI ツールの本数・PHP や Java の細部・案件（No.1〜11）の一覧。案件の詳細は締めのリンクからスキルシートへ送る（11 件を読める速さで出すと 10 秒以上かかり、「積み上げて今がある」話が一覧に変わる）
- 「営業」を本人の役割として書かない（「営業支援」は可）。FDE の話に「完了」「納品」「受注」を使わない。顧客名は出さない
- 年: エンジニア歴は 2017 年〜（10 年目）。サーバーサイドの最初の案件（No.1）は 2018年9月〜で、2017 をサーバーサイドの年にしない。層の年は サーバーサイド 2018・iOS 2018・Flutter 2021・React Native（Expo）と Web 2025・インフラと AI と CTO 2026。フリーランスは 2021年7月〜
- 強みは README の「強み」の 5 つの見出しをそのまま使う（略さない。長いものは 2 行）。README の強みを変えたら動画も合わせる
- 名前の読みは「たかはし すぐる」
- 案件で使った道具は、本人に「何をしたか」を聞いてから書く（例: BigQuery と Looker Studio は「既存の集計を見て判断した」で、自分でダッシュボードを作ったとは書かない）

## 本人が選んだ見た目と構成

- テーマカラー K1: 主役の黄 `#ffd23f`（上の文字は `#111318`）・差し色ピンク `#ff4f8b`（AI の色。上の文字は白）・文字 `#111318`・地 `#eceef1`・カテゴリ用 `#3a3f4b` `#3f6df6` `#10b98a` `#ff9f1c` `#8b5cf6`。背景は塗りつぶさず、枠と薄い塗りで見せる。今後の動画・スライドも、指定がなければこの色
- 構成（46 秒）: タイトル「46 秒でわかる 高橋 俊」（文字が中央で弾む）→「エンジニアとしての歩み」（下が支える階段に層が積まれ、縮んで柱になる。各段に年）→「技術スタック」（柱の層から各行へ線）→「5 つの強み」（README の見出し＋ロゴ。支える層から線を引き、ほかの層を薄くする）→ 番号付きの一覧 → 締め「高橋 俊のスキルシートはこちら」（スキルシートの URL はピンクの札、GitHub と X は丸いロゴのボタン）
- 場面の切り替えは、見出しを載せた黄の帯が横切る形。見出しは左上に読める大きさで残す
- 写真は `opus-3/assets/avatar.jpg`。タイトルでは角丸の四角、見出しと締めでは丸（ピンクの影）
- 尺はタイトルの数字（46 秒）と合わせる。尺を変えたらタイトルも変える
- 外された表現の一覧は `HANDOFF.md` の「本人に外された表現」にある（技術の札を 1 つずつ積む・切り抜きの枠・決め台詞・強みのカウントアップ・ロゴの無い項目・浮く層 など）

## 作業場所とファイル

- `.tmp/videos/`（コミットしない）: `STATE.md`（現在地）・`opus-3/`（採用した作品。`content.json` に中身、`HANDOFF.md` に引き継ぎ）・`versions/`（版の控え）・`mock*/`（仮アニメーションと選択票）・`bgm3/`（曲の候補）・`history.jsonl`（採った案と外した案）
- 文言・ロゴ・時刻の直しは `opus-3/content.json` を書き換えるだけで済む。見た目の直しは、`HANDOFF.md` を渡した新しい作り手に頼む
- 書き出した動画はデスクトップに `スキルシート動画_<案>_<段階>.mp4` で置く（作業ディレクトリの奥に置くだけにしない）
- ロゴはリポジトリの `assets/logos/`（技術名ごとの SVG、`logos.json` に表示名・分野・出どころ、`README.md` に代えのきまり）。足したら `opus-3/assets/logos-repo.js` を作り直す（手順は `HANDOFF.md`）
- 曲は Mixkit「What About Action?」の終わりの 46 秒（原曲の 67.222 秒の小節の頭から。約 121 BPM・1 拍 0.4959 秒）。出どころとライセンスは `opus-3/assets/MUSIC.md`。前の HeyGen の曲は、アカウントが無料プランで非商用に限られるため外した

## 公開前の確認

- 曲のページでライセンスの表示が Mixkit の Free License のままかを確かめ、画面を控える
- `motion-video` の「書き出す前の点検」（転換の途中・0 秒のコマ・スマホの幅・拍）を通す
- README を変えた後なら、動画の強みの見出しと技術の名前が README と食い違っていないか
