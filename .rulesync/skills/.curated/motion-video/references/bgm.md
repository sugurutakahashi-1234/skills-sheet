# BGM の拍の測り方

motion-video の SKILL.md の「BGM」から来る細目。曲を作る・探す・選ぶ・尺に切る・合成するのは `audio-gen` スキル（配布元の曲と合成の細目は、そのスキルの `references/sourcing.md`）。ここには、決まった曲に動きを合わせるための拍の測り方だけを置く。

- **曲は `audio-gen` スキルで作るのが既定**: 尺・BPM・ループを頼む時点で決められるため。BPM を頼んでも拍がずれることがあるので、作った曲も下の `beat-grid.py` で測り直す
- **拍は `scripts/beat-grid.py` で測る**: `uv run --with librosa --with numpy python -I "$SKILL_DIR/scripts/beat-grid.py" <曲> --bpm-hint 120`。1 拍の長さを拍の位置への直線の当てはめで出す。`--music-json <作品>/music.json` を付けると、1 拍の秒・尺・鳴り終わりと一番強い立ち上がりの拍を作品の `music.json` の形で書く（強い一撃や終わりの部分は聴いて直す）。librosa の tempo は解析の刻み幅に丸められ、数 BPM ずれて出ることがある（121 BPM の曲を 123 BPM として扱うと、35 秒で約 0.6 秒ずれて後半の動きが拍から外れる）。出た拍の表と曲の形（強い一撃・終わりの部分・鳴り終わる秒）を作り手に渡す。同じ間隔で並ぶ物（板の出る時刻など）の間隔が 4.5 拍のような半端な拍になるときは、4 拍と 5 拍の交互にして毎回拍の頭に乗せる（平均は同じ）
- ネットに出られず曲も作れないときは、`audio-gen` スキルの合成（拍の表から BGM と効果音を作る）に、この作品の拍の表を渡す
